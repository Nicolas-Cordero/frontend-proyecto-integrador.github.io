1. REQUISITOS PREVIOS
--------------------------------------------------------------------------------

NODE.JS: v16.x o superior
NPM: v8.x o superior

MACOS
───────────────────────────────────────────────────────────────────────────────

Verificar instalación:
  $ node --version
  $ npm --version

Si no tienes Node instalado:
  Opción 1 - Descargar desde: https://nodejs.org/
  Opción 2 - Usar Homebrew (recomendado):
    $ brew install node


WINDOWS
───────────────────────────────────────────────────────────────────────────────

Verificar instalación (PowerShell o CMD):
  > node --version
  > npm --version

Si no tienes Node instalado:
  1. Descarga el instalador desde: https://nodejs.org/
  2. Ejecuta el .msi
  3. Sigue el wizard (acepta todas las opciones por defecto)
  4. Reinicia tu computadora
  5. Abre PowerShell o CMD y verifica: node --version

3. INSTALACIÓN DE DEPENDENCIAS
--------------------------------------------------------------------------------

PASO 1: Navegar a la carpeta del proyecto

MACOS / LINUX
  > cd "/Users/TuUsuario/.../frontend-proyecto-integrador"

WINDOWS (PowerShell)
  > cd "C:\Users\TuUsuario\Desktop\...\frontend-proyecto-integrador"
  
  Si usas CMD (no PowerShell):
  > cd C:\Users\TuUsuario\Desktop\...\frontend-proyecto-integrador


PASO 2: Instalar dependencias (si node_modules no existe)

MACOS / LINUX / WINDOWS (igual para todos)
  $ npm install
  
  o si tienes problemas:
  $ npm install --legacy-peer-deps

Esto instalará:
  - express (v4.18.2)        → Servidor web local
  - axios (v1.6.0)           → Cliente HTTP para llamadas a API

SALIDA ESPERADA:
  added 57 packages in X.XXs
  ✓ node_modules/ creada

4. EJECUCIÓN DEL PROXY SERVER
--------------------------------------------------------------------------------

IMPORTANTE: El proxy server es CRÍTICO para que funcionen los fetchs a las
APIs remotas. Debe estar ejecutándose en todo momento.

PASO 1: Iniciar el proxy server

MACOS / LINUX / WINDOWS (igual para todos)

$ npm start

SALIDA ESPERADA:
  [proxy] Escuchando en http://localhost:3000
  [proxy] Endpoint: GET http://localhost:3000/api/mallas


PASO 2: Verificar que está funcionando

  1) Abre tu navegador (Chrome, Firefox, Safari, Edge, etc.)
  
  2) Copia y pega esta URL en la barra de direcciones:
     http://localhost:3000/html/index.html
  
  2) Si ves la página de login → ✓ Proxy está funcionando

PASO 3: Mantener el terminal abierto

  - NO cierres este terminal mientras desarrolles
  - El proxy debe estar corriendo constantemente
  - Si necesitas parar el proxy:
    
    MACOS / LINUX / WINDOWS (igual para todos)
      Presiona: Ctrl + C
